Los campos `*UsuarioID` **NO tienen FK dura** a `Usuario_Catalogo` por:
1. La tabla puede no existir en todos los ambientes
2. Migración puede traer usuarios que ya no existen
3. Logs deben preservarse si el usuario es eliminado
4. Se guarda Email como respaldo para trazabilidad

## 5. COMENTARIOS DE SEGURIDAD

### 🔒 APIHeadersConfig
```
NO almacenar tokens reales ni API keys planas.
Usar referencias a secret manager:
  {"Authorization": "SECRET_REF:api_key_servidor_123"}
El backend resuelve referencias al momento de ejecución.
```

### 🔒 ParametrosUsados (en logs)
```
JSON con valores ENMASCARADOS si son sensibles.
NO guardar contraseñas, tokens ni datos personales.
Ejemplo: {"usuario": "***", "fecha": "2026-05-12"}
```

### 🔒 SQLQuery
```
SoloLectura=1 bloquea queries que no sean SELECT.
El backend debe validar antes de ejecutar.
```

RESERVADO para futuro. NO ejecutable actualmente.
