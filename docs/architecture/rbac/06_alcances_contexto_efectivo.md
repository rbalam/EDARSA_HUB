# Alcances y contexto efectivo

## Alcances obligatorios

- Empresa
- Unidad de negocio
- Sucursal
- Propietario
- Departamento o dominio
- Contexto operativo

## Contexto regional

Precedencia:

`Usuario → Unidad → Empresa → Plataforma`

Debe aplicarse a idioma, zona horaria y configuraciones regionales.
