# Usuarios e identidades

## Usuario canónico

`Usuario_Catalogo` es el catálogo interno principal.

## Reglas

- No usar usuarios de prueba eliminados como referencia funcional.
- No mezclar usuarios internos, portales y agentes.
- Toda identidad debe tener contrato y alcance explícitos.
- Idioma y zona horaria deben resolverse mediante contexto regional canónico.
