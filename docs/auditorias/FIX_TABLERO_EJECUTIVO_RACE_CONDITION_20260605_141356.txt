FIX TABLERO EJECUTIVO COMERCIAL - PROTECCIÓN RACE CONDITIONS
================================================================================
Fecha: 2026-06-05
Archivo: /app/frontend/src/pages/TableroEjecutivo.js

PROBLEMA ORIGINAL:
- El botón "Actualizar" podía sobrescribir datos válidos con ceros
- Race conditions causaban que respuestas viejas reemplazaran nuevas
- Loading/error/fallback borraban datos existentes
- Se usaba fallback (datos mockeados) cuando V2 fallaba

SOLUCIÓN IMPLEMENTADA:

1. PROTECCIÓN RACE CONDITION (requestId):
   - requestId incremental en cada request
   - Solo se aplica respuesta si requestId === latestRequestId
   - Respuestas viejas se ignoran silenciosamente
   
2. PROTECCIÓN CONTRA SOBRESCRITURA CON CEROS:
   - Si source=V2, unidades.length > 0, pero totales=0
   - Y ya existía estado anterior con ventas > 0
   - Se BLOQUEA la actualización y mantiene datos anteriores
   - Se muestra warning al usuario

3. SEPARACIÓN LOADING/ERROR/EMPTY:
   - Loading NO limpia datos existentes
   - Error NO limpia datos existentes  
   - Stale refresh NO limpia datos existentes
   - Fallback ELIMINADO (V2 es fuente única)

4. COMPORTAMIENTO BOTÓN ACTUALIZAR:
   - Mantiene datos visibles mientras carga
   - Reemplaza solo si V2 trae datos válidos
   - Muestra error si respuesta viene vacía

5. LOGGING AGREGADO:
   - [REFRESH_LOG] START: requestId, forceRefresh, dataExists
   - [REFRESH_LOG] APPLIED: requestId, ventasTotal, unidades, source
   - [REFRESH_LOG] BLOCKED_ZERO_OVERWRITE: requestId, newVentas, existingVentas
   - [REFRESH_LOG] IGNORED_STALE: requestId, reason=stale_request
   - [REFRESH_LOG] ERROR_PRESERVED_DATA: requestId, existingDataPreserved

REGLAS CUMPLIDAS:
- ✅ No MongoDB
- ✅ No V1 fallback  
- ✅ No live visual
- ✅ V2 es fuente única
- ✅ No testing_agent_v3_fork

NUEVOS ESTADOS:
- latestRequestId: Para validar respuestas
- refreshError: Error sin borrar datos

NUEVOS COMPONENTES UI:
- Banner de error amarillo (sin borrar datos)
- Loading overlay flotante (cuando hay datos existentes)
